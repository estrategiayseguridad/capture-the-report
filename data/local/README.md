# Datos locales (no se suben a git)

Coloca aquí el CSV real exportado de Halo ITSM (todos los clientes, del mes en curso).

Esta carpeta está excluida en `.gitignore` — cualquier archivo que dejes aquí (excepto este `README.md` y `.gitkeep`) se queda solo en tu computadora y nunca se commitea ni se sube a GitHub.

Luego, en la web (`http://localhost:3000`), usa el botón **"Subir CSV de Halo ITSM"** y selecciona el archivo desde esta carpeta.
